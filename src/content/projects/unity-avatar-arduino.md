## Overview

A gesture-controlled 3D avatar built with real-time sensor data, integrating Arduino with Unity over a serial and later wireless link.

## What I did

- Built a Wi-Fi-enabled Arduino glove using IMU and flex sensors for real-time gesture capture (pitch, yaw).
- Integrated the glove with Unity 3D through ESP32-based wireless communication.
- Programmed motion mapping and avatar control in C++ (firmware) and C# (Unity).
